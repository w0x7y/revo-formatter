## Remaining limits

Line width is a soft target. Original statement line breaks stay hard, pipe chains are not independently split, expression-bodied function alignment and unary-sign spacing have basic normalization, and conservative fallback can retain compact spacing. Literal/comment interiors remain opaque. Other native/cross targets are not supported or claimed verified. Bridge region lookups repeatedly scan the token tape and can have quadratic cost on large inputs; this is a deferred performance improvement, not a preservation defect.

The work was committed on `formatter-v0` at this stage; this is a historical
workspace record, not a required current branch or checkout.
